# Probant — le dossier LCB-FT des agences immobilières, prêt pour le contrôle

Projet de business B2B construit de bout en bout : choix de l'idée, stratégie, produit testé, page de vente, pitch, prospection.

**Commencer par [`RAPPORT.md`](RAPPORT.md).**

| Dossier ou fichier | Contenu |
|---|---|
| `RAPPORT.md` | Synthèse : décisions, vérifié ou estimé, ce qu'il reste à valider avant lancement |
| `JOURNAL.md` | Avancement phase par phase, pour reprendre le travail |
| `docs/` | Recherche et choix (01), stratégie (02), offre et prix sourcés (03) |
| `produit/` | Application Probant (`dist/probant.html`), sources, 40 tests, outils de licence, exemples de documents |
| `site/` | Page de vente prête à publier (`public/`), instructions de déploiement, vérification avant mise en ligne |
| `pitch/` | Support de présentation (PDF et PowerPoint) et son générateur |
| `prospection/` | 10 prospects sourcés, brouillons de messages non envoyés, méthode et conformité |
